# ТЕХНИЧЕСКОЕ ЗАДАНИЕ (ТЗ)

## Проект: Кроссплатформенная HMI-панель и IoT-шлюз (Avalonia UI)

### 1. Общие требования и Стек

* **Платформа:** .NET 8 / .NET 9, **Avalonia UI** (MVVM паттерн, CommunityToolkit.Mvvm).
* **Кроссплатформенность:** Windows, Linux (включая ARM/Raspberry Pi), Android (для планшетов/смартфонов).
* **Архитектура конфигурации:** Полное описание системы (подключения, шлюзы, экраны, виджеты) хранится в одном файле формата **JSON** с возможностью импорта/экспорта.

---

### 2. Подсистема связи и Источники данных (Data Core)

Приложение должно абстрагировать источник данных. Для UI любой тег — это реактивное свойство, независимо от протокола.

#### 2.1. Модуль Modbus (Драйверы)

* **Протоколы:** Modbus TCP, Modbus RTU over TCP.
* **Режимы опроса:** Асинхронный, циклический (таймаут опроса задается для каждого подключения отдельно, дефолт — 200–500 мс).
* **Оптимизация трафика:** Автоматическая группировка смежных регистров в один Modbus-пакет (групповое чтение функциями `0x03`, `0x04`, `0x01`, `0x02`).
* **Поддержка Word/Byte Order (Endianness):** Переключаемый формат упаковки для 32- и 64-битных типов данных (`Float32`, `DINT`, `Double`). Варианты: **ABCD**, **CDAB**, **BADC**, **DCBA**.

#### 2.2. Модуль MQTT

* **Функционал:** Подключение к MQTT-брокеру, подписка (Subscribe) на топики для чтения и публикация (Publish) для управления.
* **Качество обслуживания:** Поддержка QoS 0, 1, 2.

#### 2.3. Модуль Ретрансляции (IoT Bridge)

* Фоновая служба двунаправленного обмена данными:
* **Modbus $\rightarrow$ MQTT:** Публикация в топик при изменении значения регистра (или по таймеру).
* **MQTT $\rightarrow$ Modbus:** Запись в регистр ПЛК при поступлении нового сообщения из топика.



---

### 3. Подсистема интерфейса (UI) и Контролы

Интерфейс строится по принципу адаптивной плиточной сетки (Dashboard Grid), аналогично концепции MQTT Dash. Каждая плитка — это `UserControl` в Avalonia.

#### 3.1. Базовые контролы

* **Value Display:** Текстовый вывод (Int/Float), масштабирование значений ($4-20\text{мА} \rightarrow 0-100\%$), форматирование строк (`{0:F2} °C`).
* **Pilot Light:** Светодиод/индикатор состояния бита или маски. Кастомные цвета (True/False/No Connection).
* **Progress Bar / Gauge:** Линейные и круговые индикаторы уровня/давления.
* **Command Button:** Кнопка отправки команд. Режимы: Импульсная (Momentary: 1 при нажатии, 0 при отпускании), Фиксация (Toggle), Запись константы (Set Value).
* **Slider / Setpoint Input:** Ползунки и поля ввода уставки. Поля ввода должны вызывать встроенный в приложение **Numpad Popup** (цифровую клавиатуру), чтобы не зависеть от системной клавиатуры ОС.
* **Real-Time Trend:** Легковесный график для вывода истории параметра из RAM-буфера (на базе LiveCharts2 или ScottPlot).

#### 3.2. Контрол-контейнер (Container Button)

* Плитка на главном экране, которая при клике открывает всплывающее модальное окно (`Popup` или дочерний `Window`).
* Внутри окна разворачивается **собственная вложенная сетка дашборда**, куда можно добавлять любые другие контролы из списка выше.

---

### 4. Редактор конфигурации (Инженерный режим)

Приложение имеет два режима: *Исполнение (Runtime)* и *Конфигурирование (Design)*.

* **Редактор подключений:** UI-форма для добавления/редактирования ПЛК и MQTT-брокеров (IP, порты, ID устройств, выбор дефолтного Byte Order).
* **Конструктор экранов:** Drag-and-drop или сеточный выбор для размещения виджетов, привязка виджета к источнику данных (выбор подключения, адреса регистра/топика и типа данных).

---

### 5. Структура JSON-файла конфигурации (Спецификация)

```json
  "BridgeRules": [
    { "Name": "String", "Source": { "ConnId": "Str", "Address": "Str" }, "Destination": { "ConnId": "Str", "Address": "Str" }, "Direction": "BiDir|SrcToDst" }

      {
        "Type": "ValueDisplay|PilotLight|ContainerButton|...",
        "Title": "String",
        "Source": { "ConnId": "Str", "Address": "Str", "DataType": "Str" },
        "Position": { "Row": "Int", "Col": "Int", "SizeX": "Int", "SizeY": "Int" },
        "Children": [ /* Только для ContainerButton */ ]
      }
    ]
  }
}

```
