## 📅 15.06.2026 (Сессия 5 — Переработка контрола клапана)

### 📌 Достижение: Единый промышленный ValveControl с поддержкой приводов и поворота
*   **Новый контрол клапана:** Создан класс `ValveControl.cs` (взамен старого `RegulatingValveControl.cs`), реализующий единую логику отрисовки задвижек/клапанов.
*   **Типы приводов (ActuatorType):** Поддержаны 4 режима отображения привода над штоком:
    *   `Solenoid` (электромагнитный/электропривод) — желтый прямоугольник с буквой `S` (для отсечных) или `P` (для регулирующих) согласно стилистике SCADA с предоставленного снимка экрана.
    *   `Diaphragm` (пневматический мембранный) — дугообразный купол с плоской тарелкой.
    *   `Manual` (ручной) — Т-образный штурвал.
    *   `None` — без привода (только корпус).
*   **Поворот на 90° (IsVertical):** Реализовано свойство `IsVertical`. При активации весь контрол (корпус, шток, фланец, привод) поворачивается на 90 градусов для идеального позиционирования на вертикальных участках трубопроводов без искажения пропорций.
*   **Инженерное меню (Design Mode):** 
    *   В модель `WidgetConfig` и вьюмодели `ValveWidgetViewModel.cs` / `WidgetEditorViewModel.cs` добавлены свойства `IsVertical` и `ActuatorType`.
    *   В форму настроек `WidgetEditorWindow.axaml` встроены ComboBox для выбора типа привода и CheckBox для включения вертикальной ориентации.
*   **Интеграция с тегами:** Цвета открытого/закрытого клапана теперь динамически берутся из настроек `ActiveColor`/`InactiveColor`. Для регулирующих клапанов цвет плавно интерполируется между ними в зависимости от положения `Feedback`.
*   **Очистка и регенерация конфигурации:** Устаревший класс `RegulatingValveControl.cs` удален. Файлы кэша `config.json` очищены для автоматического применения новых свойств при первом запуске приложения.
