# План Реализации: Логическое прилипание труб и «резиновые» соединения (Rubber-banding)

Реализация механизма динамической связи между трубопроводами (Pipe) и регулирующей/отсечной арматурой (Valve, Pump). При перемещении задвижки или насоса присоединенные к ним трубы должны автоматически растягиваться/сжиматься («резиновая связь»), следуя за движением портов в реальном времени.

## Proposed Changes

### 1. Доработка [DashboardPanel.cs](file:///c:/Users/ess2/source/repos/AvaloniaApplication1/AvaloniaApplication1/Views/DashboardPanel.cs)

Добавить структуру для хранения информации о подключенной трубе и отслеживать связи при перетаскивании виджетов:

* **Структура связи:**
  ```csharp
  private struct ConnectedPipePoint
  {
      public PipeWidgetViewModel PipeVm;
      public int PointIndex;
      public bool IsPort1; // true для левого/верхнего порта, false для правого/нижнего
  }
  ```
* **Поля класса:**
  ```csharp
  private List<ConnectedPipePoint> _connectedPipePoints = new();
  ```
* **Сбор связей при начале перетаскивания (в `OnPointerPressed`):**
  Когда начинается перетаскивание виджета (если `vm.Type` это Valve или Pump):
  1. Вычислить точные текущие координаты портов `Port 1` и `Port 2` в сетке (с учетом ориентации `IsVertical` и размеров `SizeX`/`SizeY`).
  2. Найти все трубы (`PipeWidgetViewModel`) в текущем контейнере.
  3. Для каждой трубы проверить координаты всех её точек (особенно крайних). Если координата точки совпадает с координатой порта задвижки, добавить запись в список `_connectedPipePoints`.
* **Обновление труб в процессе движения (в `OnPointerMoved`):**
  Когда виджет перемещается (или привязывается к новой координате):
  1. Вычислить новые координаты портов `Port 1` и `Port 2` на основе текущих `Col` и `Row` перемещаемой задвижки/насоса.
  2. Для каждого элемента из списка `_connectedPipePoints` обновить соответствующую точку в коллекции точек трубы.
  3. Перегенерировать строку `PipePoints` для вьюмодели трубы и обновить её, вызвав перерисовку.
* **Очистка при отпускании мыши (в `OnPointerReleased` / `LostFocus`):**
  Очистить коллекцию `_connectedPipePoints`.
