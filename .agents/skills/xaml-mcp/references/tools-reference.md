# Подробный справочник инструментов XamlMcp (API Reference)

Полная спецификация всех инструментов MCP-сервера `trrahul/XamlMcp`.

---

## 1. Управление подключением

### `list-apps`
Возвращает список обнаруженных запущенных приложений, в которые внедрен агент `XamlMcp.Avalonia`.
* **Вывод**: Массив объектов:
  * `instanceId`: Уникальный идентификатор экземпляра (например, `desktop-12345-abcde`).
  * `pid`: Идентификатор процесса ОС.
  * `platform`: `Desktop` / `Android`.
  * `framework`: `Avalonia`.
  * `windowTitle`: Заголовок главного окна.

### `attach`
Подключается к выбранному приложению.
* **Аргументы**:
  * `instanceId` *(string, обязательный)*: Идентификатор из `list-apps`.
* **Вывод**:
  * Информация о подключении и список возможностей (capabilities), поддерживаемых фреймворком (например, поддержка `pseudo-class`, `styles`, `screenshot`, `bindings`).

### `detach`
Освобождает соединение и закрывает сопутствующие ресурсы канала named-pipe.
* **Аргументы**: *нет*.

## 2. Инспекция визуального и логического дерева

### `tree`
Получает снимок (snapshot) дерева контролов.
* **Аргументы**:
  * `depth` *(integer, опционально)*: Максимальная глубина обхода (по умолчанию: всё дерево).
  * `profile` *(string, опционально)*: `"full"` или `"semantic"` (компактный вид, пропускающий промежуточные безымянные декораторы Border/Panel).
  * `within` *(node locator, опционально)*: Корневой узел, от которого строить дерево.
* **Вывод**: Иерархическое дерево с `nodeId`, `type`, `name`, `bounds` $(X, Y, W, H)$, `visibility`.

### `search`
Быстрый поиск узлов по селекторам.
* **Аргументы**:
  * `name` *(string, опционально)*: Поиск по `Name` / `x:Name`.
  * `type` *(string, опционально)*: Поиск по имени класса контрола (например, `ValveControl`, `TextBox`, `Button`).
  * `text` *(string, опционально)*: Поиск по содержимому текста (TextBlock.Text, Button.Content).
  * `automationId` *(string, опционально)*: По значению `AutomationProperties.AutomationId`.
  * `styleClass` *(string, опционально)*: По классу стилей Avalonia (например, `danger`, `active`).
  * `within` *(node locator, опционально)*: Область поиска.
* **Вывод**: Список найденных узлов с их `nodeId` и краткими метаданными.

### `ancestors`
Возвращает цепочку предков узла от текущего элемента до корня окна.
* **Аргументы**:
  * `target` *(node locator / nodeId, обязательный)*.

## 3. Свойства, стили и привязки (Data Binding)

### `props`
Считывает свойства контрола (DirectProperty, StyledProperty).
* **Аргументы**:
  * `target` *(node locator, обязательный)*.
  * `names` *(string[], опционально)*: Список конкретных свойств для чтения (например, `["IsActive", "Value", "Background"]`).
* **Вывод**: Имя свойства, текущее значение, источник значения (Default, Style, Local, Binding), доступные шаблоны автоматизации.

### `set-prop`
Устанавливает локальное значение свойства контрола или сбрасывает его.
* **Аргументы**:
  * `target` *(node locator, обязательный)*.
  * `name` *(string, обязательный)*: Имя свойства.
  * `value` *(any)*: Новое значение (или `null` / `"__unset__"` для сброса до уровня стиля).

### `bindings`
Диагностика выражений Data Binding.
* **Аргументы**:
  * `target` *(node locator, обязательный)*.
* **Вывод**: Путь к свойству во ViewModel (`Path`), текущий `DataContext`, режим привязки (`OneWay`, `TwoWay`), конвертеры и ошибки типизации.

### `failures`
Возвращает перехваченные ошибки привязок (Binding Errors) и исключения UI-диспетчера.
* **Аргументы**:
  * `categories` *(string[], опционально)*: `["binding", "dispatcher"]`.
  * `cursor` *(string, опционально)*: Курсор отслеживания изменений после предыдущего действия.

### `pseudo-class`
Принудительно включает или отключает псевдоклассы Avalonia 11+ для проверки визуальных состояний.
* **Аргументы**:
  * `target` *(node locator, обязательный)*.
  * `name` *(string, обязательный)*: Имя псевдокласса, например `:pointerover`, `:pressed`, `:disabled`, `:selected`.
  * `value` *(boolean, обязательный)*: `true` для активации, `false` для деактивации.

## 4. Скриншоты и визуальный рендеринг

### `screenshot`
Захватывает растровое изображение элемента или окна в формате PNG через `RenderTargetBitmap`.
* **Аргументы**:
  * `target` *(node locator, опционально)*: Если не указан — снимок всего активного окна. Если указан — снимок конкретного контрола.
* **Вывод**: MCP Image (передается напрямую визуальной модели для оценки верстки).

---

## 5. Ввод и симуляция действий

### `input`
Синтезирует системные события мыши и клавиатуры.
* **Аргументы**:
  * `target` *(node locator, опционально)*.
  * `type` *(string, обязательный)*: `"click"`, `"double-click"`, `"right-click"`, `"text"`, `"key-press"`, `"scroll"`.
  * `text` *(string, для ввода текста)*.
  * `key` *(string, для нажатия клавиши, например, `"Enter"`, `"Escape"`)*.

### `action`
Вызывает стандартные паттерны UI Automation или привязанные `ICommand`.
* **Аргументы**:
  * `target` *(node locator, обязательный)*.
  * `pattern` *(string, обязательный)*: `"invoke"`, `"toggle"`, `"select"`, `"expand"`, `"collapse"`.
